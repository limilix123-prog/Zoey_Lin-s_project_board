#A project dashboard modeled after Huawei's project management dashboard. All code was written by AI.

How to Run:

python --version (3.10+ · pip · Win PS 5.1+)
pip install Flask Jinja2
Expand-Archive release_v0.9.8.0_demo.zip
$env:PYTHONIOENCODING="utf-8"
flask --app project_board.app.feature_app_factory:create_app run 
http://127.0.0.1:5000 · kylins / kylins123

Design Concept:
dont ask a agent for more than 1 skill.
dont give a agent too more message that it wont use.
only use harness if necessary.
